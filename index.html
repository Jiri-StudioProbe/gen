🌳 Family Tree

Demo mode — sample data, nothing is saved.

Open a folder to begin

Family Tree stores your data as plain Markdown files in a folder you choose — the same folder can be opened as an Obsidian vault. Nothing leaves your machine.

Your browser doesn't support the File System Access API — this needs desktop Chrome or Edge (it isn't available on iOS/iPadOS at all, in any browser, since none of them can use a different engine there). Try the demo below instead to explore the UI.
